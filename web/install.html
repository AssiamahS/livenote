Install LiveNote

Type a note, it sits on your Lock Screen and in the Dynamic Island until you clear it. Direct install for registered iPhones. No App Store, no TestFlight.

Install on this iPhone

This page is open inside another app, not Safari. Tap … (or the share icon) and choose Open in Safari, then install from there.

  1. Open this page in the real Safari app, not inside Claude, Messages or X.
  2. Tap Install. iOS asks Open in “iTunes”? → tap Open. Then Install on the “would like to install LiveNote” prompt.
  3. It lands in the App Library (search for it if it's not on a Home Screen page).

Set up the Action button

  1. Shortcuts app → + → search LiveNote → Create & Go Live.
  2. Leave Text empty so it asks you every time. Expand the action and turn off Show When Run.
  3. Settings → Action Button → Shortcut → pick it. Back Tap, Control Center and a Lock Screen control work too.
